Subshell Extract + but amend

Extract commit ID then amend a change into it
Uses command substitution to get the commit cliId, then passes it to but amend.
CID=$(but status --json 2>&1 | python3 -c "import json,sys; \
  d=json.load(sys.stdin); \
  branch = [s for s in d['stacks'] \
    if any(b['name']=='topics-feature' for b in s['branches'])][0]; \
  print(branch['branches'][0]['commits'][0]['cliId'])") \
  && but amend ns $CID --json 2>&1
{"new_commit_id": "0009d25a7c26aa3ba4672a8abbc3a130edf75354", "ok": true}
Same pattern with --status-after
